# Benchmark Method Comparison

Generated on 2026-06-22 from stored benchmark artifacts in `horizyn/results`.

This document compares all benchmarked retrieval methods currently represented in the aggregate result table plus the newer complete benchmark runs that were tested afterward. `R2E` means `reaction_to_enzyme`; `E2R` means `enzyme_to_reaction`. Values are fractions, so `0.2262` means 22.62% MRR.

## Data And Protocol Notes

- Horizyn SOTA evaluates reaction-to-enzyme retrieval on the original Horizyn held-out test set.
- ReactZyme `time`, `enzyme_smi`, and `reaction_smi` evaluate both retrieval directions.
- `enzyme_smi` R2E is the hardest split for these models: the reactions are seen, but nearly all target enzymes are unseen/sequence-distant and must be ranked against a large candidate bank.
- `original_test`, `protein_disjoint_exact`, `protein_disjoint_nr90`, and `unfiltered_original` are not identical protocols. Compare rows within a protocol when making strict claims; use the overall columns only as a broad orientation score.
- `Overall mean MRR` and `Overall harmonic MRR` average the available MRR columns in that row. Harmonic MRR penalizes weak directions more strongly.

## Quick Takeaways

- Best overall non-smoke row by harmonic MRR: **R07 ProtT5 + ReactionT5v2/UniMol2 epoch10** with harmonic MRR `0.5147`.
- Best overall non-smoke row by arithmetic mean MRR: **R07 ProtT5 + ReactionT5v2/UniMol2 epoch10** with mean MRR `0.6377`.
- Best `EnzSMI R2E` row: **R07 ProtT5 + ReactionT5v2/UniMol2 epoch10** with EnzSMI R2E MRR `0.2262`.
- The strongest broad pattern is that the simple ProtT5 mean-pooled enzyme stack with ReactionT5v2 + UniMol2 attention remains the most robust overall, while SLEEC/Lorentz variants are stronger on some Horizyn-style settings but weaker on several ReactZyme directions.
